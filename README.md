# Week 4: Building SQL-based Data Reports and Visualizations

## Project Overview

This project focuses on integrating SQL querying skills with data reporting and visualization concepts. The main objective is to convert raw relational database data into meaningful reports and actionable insights using SQL queries and suitable visual representations.

A sample retail database scenario is used for this project. The database contains Customers, Products, Orders, and OrderItems tables. SQL queries are designed to extract, filter, aggregate, and summarize the data required for reporting.

---

## Objectives

The main objectives of this project are:

- Extract meaningful information using SQL queries.
- Transform raw database data into report-ready datasets.
- Apply filtering and aggregation techniques.
- Calculate important business metrics and KPIs.
- Design suitable visualizations for different types of data.
- Present data in a clear and understandable format.
- Maintain data accuracy and integrity throughout the reporting process.
- Apply data storytelling principles to communicate insights.

---

## Database Structure

The project uses a sample retail database containing four main tables.

### 1. Customers

Stores customer-related information.

**Columns:**
- `customer_id`
- `customer_name`
- `city`
- `email`

### 2. Products

Stores product information.

**Columns:**
- `product_id`
- `product_name`
- `category`
- `price`
- `stock`

### 3. Orders

Stores information about customer orders.

**Columns:**
- `order_id`
- `customer_id`
- `order_date`
- `status`

### 4. OrderItems

Stores individual products included in each order.

**Columns:**
- `order_item_id`
- `order_id`
- `product_id`
- `quantity`

## SQL Reports Developed

### 1. Sales Performance by Product

This report calculates the number of units sold and total revenue generated by each product.

The query uses:

- `JOIN`
- `SUM()`
- `GROUP BY`
- `ORDER BY`
- `WHERE`

The result can be represented using a bar chart or detailed table.

---

### 2. Monthly Sales Trend

This report calculates the number of completed orders for each month.

The result can be displayed using a **line chart** to identify changes and trends in sales activity over time.

---

### 3. Customer Order Summary

This report calculates the total number of orders placed by each customer.

A bar chart can be used to compare customer activity, while a table can provide the exact values.

---

### 4. Revenue by Category

This report calculates total revenue generated by each product category.

A **bar chart** is recommended because it makes category-level revenue comparisons easy to understand.

---

### 5. Order Status Distribution

This report calculates the number of orders for each order status.

The result can be displayed using a column chart or another simple proportion-focused visualization.

---

## Key Performance Indicators (KPIs)

The following KPIs can be included in the final report:

| KPI | Description |
|---|---|
| Total Completed Orders | Number of orders with Completed status |
| Total Revenue | Revenue generated from completed orders |
| Units Sold | Total quantity of products sold |
| Top Product | Product generating the highest completed-order revenue |

KPI cards can be placed at the top of the report to provide a quick overview of business performance.
